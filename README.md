Kanban Vagas

Aplicação Full Stack desenvolvida para organizar e acompanhar candidaturas a vagas de emprego através de um quadro Kanban.

O projeto está sendo desenvolvido com foco na construção de uma aplicação completa, desde a API e persistência dos dados até a interface do usuário.

Principais funcionalidades:

Cadastro de vagas
Listagem de candidaturas
Atualização do status das vagas
Exclusão de vagas
Organização das candidaturas através de um Kanban
Integração entre Front-end e API REST

Tecnologias:

React • TypeScript • Node.js • Express • PostgreSQL • Prisma • Vite
